このページについて

Snapknow（以下「当方」）は、AIとテクノロジーのニュースを短尺動画で配信する個人事業です。 このプライバシーポリシーは、当方が運営するウェブページおよび当方が利用するソフトウェアにおける 情報の取り扱いを説明するものです。

1. このサイトが集めない情報

当サイトは静的なページであり、入力フォームを設置していません。 氏名・メールアドレス・電話番号・住所などを当方が直接収集することはありません。 アカウント登録の仕組みもありません。

2. ブラウザに保存されるもの

当サイトが閲覧者のブラウザに情報を保存することはありません。

（2026-08-31まで、表示言語の選択をローカルストレージに保存する機能がありましたが、 多言語表示の廃止に伴い削除しました。過去に保存された値が端末に残っている場合は、 ブラウザの設定でサイトデータを削除すれば消去できます。）

3. アフィリエイトリンクについて

当サイトおよび当方の動画の説明文には、アフィリエイトリンクを含むことがあります。 該当箇所には #PR などの表記を行っています。

リンクをクリックすると、広告主またはアフィリエイトサービスプロバイダ（ASP）が 成果測定のためにCookieを設定する場合があります。これは各社の管理下にあり、当方が設定するものではありません。

当方がASPから受け取るのは、クリック数や成果件数などの集計値のみです。 購入者個人を特定できる情報（氏名・住所・カード情報など）を当方が受け取ることはありません。

各社の取り扱いについては、リンク先およびASPのプライバシーポリシーをご確認ください。

4. アクセスログ

当サイトはNetlify社のホスティングサービス上で公開されています。 サービス提供の過程で、IPアドレス・ブラウザの種類・アクセス日時などが同社に記録される場合があります。 当方はこれらを個人の特定に用いません。

当方は現時点でアクセス解析ツール（Google Analytics等）を当サイトに設置していません。

5. 外部サービスへのリンク

当サイトはYouTube・TikTok・Instagram および広告主のページへのリンクを含みます。 リンク先での情報の取り扱いは各社のプライバシーポリシーに従います。当方は責任を負いません。

6. Google APIの利用について

当方は、自らが運営するYouTubeチャンネルの成績を記録・分析する目的で、 Google の API（YouTube Data API v3 および YouTube Analytics API）を利用しています。

  • アクセスするのは当方自身が所有するチャンネルのデータに限られます。 他者のチャンネルやアカウントにアクセスすることはありません
  • 権限は読み取り専用です。動画の投稿・編集・削除は行いません
  • 取得するのは再生数・視聴時間・視聴維持率などの集計された指標のみで、 視聴者個人を特定する情報は含まれません
  • 取得したデータは当方の管理する端末内に保存し、 第三者に提供・販売・譲渡しません。広告目的にも使用しません

Google APIから受け取った情報の当方による利用および他者への移転は、 「限定的な使用」の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

この連携は、Googleアカウントの 「サードパーティ製のアプリとサービス」 からいつでも解除できます。

7. 子どもの利用について

当サイトは特定の年齢層を対象としたサービスではなく、 13歳未満の方から意図的に情報を収集することはありません。

8. 改定

本ポリシーは必要に応じて改定します。改定した場合はこのページの最終更新日を更新します。

9. お問い合わせ

本ポリシーに関するお問い合わせは tamtamcompa@gmail.com までご連絡ください。
